#   search=yes     In Suchergebnissen und KI-Antworten zeigen — erwuenscht.
#   ai-input=yes   Als Quelle fuer KI-Antworten benutzen — ebenfalls erwuenscht.
#                  Genau dafuer gibt es die llms.txt. Cloudflares Beispiel
#                  schlaegt hier "no" vor; das waere fuer diese Seite verkehrt.
#   ai-train=no    Zum Trainieren von Modellen verwenden — nicht erwuenscht.
#                  Gefunden werden ja, kostenlos Trainingsmaterial liefern nein.

# /community/ steht bewusst NICHT hier:
# Die Seite traegt noindex und wird von jeder Seite aus verlinkt. Wer sie in
# robots.txt sperrt, verhindert genau das Lesen dieses noindex — Google kennt
# die Adresse dann durch die Verweise, darf aber nicht nachsehen, und traegt sie
# als blossen Eintrag ohne Ausriss in den Index ein. Beide Signale zusammen
# arbeiten gegeneinander; noindex allein wirkt.

# ── Crawler von Sprachmodellen ─────────────────────────────────────────────
#
# Technisch aendert dieser Abschnitt nichts: Das `User-agent: *` oben erlaubt
# sie bereits, und geprueft ist es auch — alle unten genannten bekommen auf
# /tools/research/ eine 200.
#
# Er steht hier trotzdem, aus zwei Gruenden. Erstens liest ein Crawler die
# Regeln zu seinem eigenen Namen und ignoriert dann den Stern; wer spaeter am
# Stern schraubt, sperrt sie sonst versehentlich mit aus. Zweitens ist damit
# schriftlich, dass das Auslesen erwuenscht ist — diese Seite lebt davon,
# gefunden und zitiert zu werden.
#
# Jede Gruppe wiederholt die beiden Sperren. Das ist kein Versehen: Wer seinen
# eigenen Namen in der Datei findet, liest die Stern-Gruppe nicht mehr — ohne
# die Wiederholung stuenden /admin/ und /profile/ genau diesen Crawlern offen.
#
# Wichtig fuer diese Seite: Keiner dieser Crawler fuehrt JavaScript aus. Die
# Rechner sind fuer sie leer; lesbar sind die Seiten unter /costs/ und der
# Wegweiser /llms.txt.
